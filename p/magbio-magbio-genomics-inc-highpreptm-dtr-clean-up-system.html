MagBio Genomics, Inc. HighPrep™ DTR Clean-up System

by Magbio Genomics, INC.

Sanger sequencing reaction clean-up / dye terminator removal

What this type of device does: A collection of reagents and other associated materials intended to be used for the construction of fragmented nucleic acids [deoxyribonucleic acid (DNA) or ribonucleic acid (RNA)] for use in genomic sequencing assays. It typically consists of buffers, primers, enzymes (e.g., DNA polymerase, DNA ligase) and deoxynucleotides (dNTPs) and is intended to be used for whole genome and/or complementary deoxyribonucleic acid (cDNA) library construction.
