Radiography 7300 C 712037

by Philips Medical Systems Dmc GmbH

Radiography 7300 C is a high-end digital radiography system consisting of a height adjustable patient support table and a ceiling suspension consisting of a tube including a control handle used to acquire images with a flat panel fixed RAD detector. Additionally, different vertical stands for the radiography examinations are available. The ceiling suspension can be moved in longitudinal and lateral directions and additionally the tube can be tilted and rotated as well. The proposed Radiography 7300 C is configured with a Philips x-ray generator and a flat panel fixed RAD detector, Pixium 4343RCE. Together with the tube these components form the radiography Image Chain. The additional option of the portable wireless detector i.e. the SkyPlate family can be used for free exposures as well as in the patient support table or in the vertical stand. The proposed Radiography 7300 C uses the following Accessories, • Parking frame for accessories • Handgrips • Side Bar • Adjustable straps • Compression Belt • Infusion Bottle holder TH-S • Infusion Bottle holder TH2 • Support for CPR (Cardio Pulmonary Resuscitation) • Stretch Grip • Remote control holder • Charger 2EZ • Grid’s for Skyplayte Wireless Portable Detectors • Grid’s for Fixed Detectors • Detector Handle • Detector holder for patient bed • Mobile detector holder • Portable panel protector • WPD Hygienic bags • Patient support • Adjustable Straps for Patient Support • Stitching Ruler Radiography 7300C is a successor of DigitalDiagnost C90 (Release Version 1.1). The main differences of Radiography 7300 C versus DigitalDiagnost C90 are optional new features: • Assisted collimation & Assisted detector height alignment (Smart Collimation Thorax / SCT) • Overlays including On-screen collimation & AEC Visualization

What this type of device does: An assembly of devices that comprise general-purpose stationary diagnostic x-ray system used in a variety of routine planar x-ray imaging applications. It uses digital techniques for image capture, display and manipulation. The stationary design requires it to be installed and used in a fixed location within a building or in a transportation van (a mobile imaging van). This system consists of modular configurations that can be upgraded by the addition of hardware/software components. This GMDN code does not cover systems with fluoroscopic or tomographic capabilities.
